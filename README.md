# ☕ Aroma Coffee Shop

## 📌 Project Overview

Aroma Coffee Shop is a responsive coffee shop website developed using HTML5 and CSS3. The project presents a modern and user-friendly interface where visitors can explore the coffee menu, learn about the shop, view popular drinks, and get in touch through the contact section.

## 🎯 Project Objectives

- Build a clean and attractive coffee shop website.
- Practice semantic HTML5 structure.
- Create responsive layouts using CSS.
- Design reusable and visually appealing components.
- Improve understanding of Flexbox and CSS Grid.
- Implement hover effects and smooth transitions.
- Create a mobile-friendly website without JavaScript.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- CSS Media Queries
- CSS Transitions
- Responsive Web Design

## ✨ Features

- Responsive navigation bar
- Hero section with call-to-action button
- About Us section
- Coffee menu with product cards
- Coffee prices and order buttons
- Feature cards for coffee shop highlights
- Contact information section
- Contact form with HTML validation
- Responsive design for desktop, tablet, and mobile
- Hover effects and smooth CSS transitions
- Semantic HTML elements
- Accessible image descriptions using `alt` attributes
- Smooth scrolling between sections
